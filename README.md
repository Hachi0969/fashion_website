# Maison Noir Static Homepage

A lightweight, static high-fashion homepage inspired by minimalist editorial commerce sites.

## Files

- `index.html` - page structure
- `style.css` - responsive visual design
- `script.js` - automatic hero image carousel
- `bg1.jpg`, `bg2.jpg`, `bg3.jpg` - placeholder images to replace with your own photos

## Edit

Replace `bg1.jpg`, `bg2.jpg`, and `bg3.jpg` with your final campaign photos using the same file names.
